# 🖥️ Student Portal - Frontend (React + Vite)

This is the frontend component of the Lecture Assignment System. It is built with **React**, **Vite**, and **Tailwind CSS**.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Run Tests
```bash
npm test
```

## 🧪 Testing Architecture
- **Vitest**: Modern testing framework.
- **React Testing Library**: Component interaction testing.
- **Mock Service Worker (Optional)**: For API mocking.

## 📁 Key Directories
- `src/components`: Reusable UI components.
- `src/pages`: Page-level components.
- `src/context`: Global state management (Auth).
- `src/services`: API interaction logic.
